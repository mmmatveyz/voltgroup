## 🛠 Архитектура и модули

### 1. Публичный сайт (`index.html`)
* **Дизайн:** Современный киберпанк / Dark Tech стиль с фирменными неоновыми акцентами Cyan (`#00E5FF`). Полная адаптивность (Mobile, Tablet, Desktop).
* **Секции:**
  * Главный экран с УТП, кнопками расчёта сметы и связи в Telegram/WhatsApp.
  * Блок ключевых преимуществ: штробление без пыли со строительным пылесосом, работа по ПУЭ-7 и ГОСТ, официальный договор и гарантия 12 месяцев.
  * Каталог базовых цен по видам работ (черновой монтаж, щитовое оборудование, чистовой монтаж).
  * Интерактивная фотогалерея выполненных работ с фильтрацией по бейджам и тегам (`gallery/gallery-config.json`).
  * Зоны обслуживания: интерактивная карта районов СПб и ЛО.
  * Отзывы клиентов, блок частых вопросов (FAQ) и форма заявки.
* **Юридические страницы:**
  * `privacy.html` — Политика обработки персональных данных (ФЗ-152).
  * `offer.html` — Публичная оферта на оказание услуг.
  * `cookies.html` — Политика использования файлов cookie.

### 2. Интерактивная смета и документооборот (`estimate.html`)
Полноценное рабочее место мастера для составления расчётов прямо на объекте или удалённо:
* **Каталог позиций:** Более 100 наименований электромонтажных работ из `prices.json` с группировкой по категориям (штробление, кабель, подрозетники, электрощит, освещение, слаботочка, демонтаж).
* **Умный поиск и фильтрация:** Моментальный поиск по наименованию и переключатель «Только выбранные».
* **Коэффициент сложности:** Переключатель `+20%` (сложные условия / монолит / бетон) для каждой позиции отдельно.
* **Произвольные работы и материалы:** Возможность добавления собственных строк с автоматическим фокусом, удобной навигацией по клавише `Enter` и моментальным пересчётом на лету (`oninput`).
* **Управление закупкой материалов:** Переключатель «Мастер закупает материалы» (включаются в итоговую сумму к оплате) / «Материалы предоставляет заказчик».
* **Гибкая скидка:** Слайдер персональной скидки от 0% до 20% с автоматическим пересчетом выгоды.
* **Сохранение черновиков:** Экспорт и импорт черновика сметы в файл `.json` для продолжения работы на другом устройстве.
* **Формирование документов (печать / сохранение в PDF):**
  * 📑 **Договор бытового подряда:** официальный договор по ГК РФ (§ 1, 2 гл. 37) и 422-ФЗ со спецификацией работ и материалов в Приложении № 1.
  * 📄 **Коммерческое предложение (КП):** презентабельный документ с фирменным стилем VoltGroup, подробными условиями и преимуществами.
  * 📝 **Акт сдачи-приёмки работ:** официальный акт по ст. 720 ГК РФ с фиксацией отсутствия претензий и гарантией 12 месяцев.
  * 🖨 **Печатная смета (PDF):** аккуратная структурированная смета формата А4.
  * 📊 **Экспорт в Excel (.csv):** выгрузка таблицы с сохранением структуры и кодировки UTF-8 BOM.
  * 📋 **Копирование для мессенджеров:** форматированный текст со смайлами для отправки клиенту в Telegram/WhatsApp в 1 клик.

### 3. Telegram-бот и мини-CRM (`server.py`)
Интерактивный бот для мастера с управлением через **Inline-кнопки** (без необходимости помнить текстовые команды):
* **База данных:** SQLite (`voltgroup.db`) с автоматической миграцией таблиц `projects` и `project_photos`.
* **Управление объектами:**
  * Добавление нового объекта (клиент, адрес, телефон, стоимость по смете, аванс).
  * Просмотр карточки объекта с финансовым балансом (Смета / Оплачено / Остаток к оплате).
* **Интерактивные действия в 1 клик:**
  * 📊 **Прогресс выполнения:** кнопки быстрого выбора `10%`, `25%`, `50%`, `75%`, `90%`, `100%` с визуальным прогресс-баром `[▓▓▓▓▓░░░░░] 50%`.
  * ⚙️ **Этапы работ:** быстрый перевод между этапами: *Черновой монтаж* ➔ *Сборка щита* ➔ *Чистовой монтаж* ➔ *Сдача объекта*.
  * 💰 **Внесение оплаты:** добавление платежа с мгновенным пересчетом остатка задолженности.
  * 📸 **Фотоотчёты:** загрузка фото прямо в чат бота с привязкой к этапу объекта.
  * 🔗 **Ссылка для заказчика:** генерация готовой ссылки на личный кабинет клиента.

## 📑 Генерация документов и юридическая база

Все генерируемые документы в калькуляторе соответствуют законодательству РФ и оформлены в стандартах делового документооборота:

| Документ | Нормативная база | Особенности и содержание |
|---|---|---|
| **Договор подряда** | Гл. 37 ГК РФ (ст. 702–739), ФЗ № 422-ФЗ | Права и обязанности, правила ПУЭ-7, СП 256, гарантия 12 месяцев, порядок расчетов, Приложение № 1 (Спецификация) |
| **Коммерческое предложение** | Гражданский кодекс РФ (оферта) | Фирменный стиль, список работ, сроки действия (3 дня), порядок оплаты, ценности и стандарты чистоты |
| **Акт сдачи-приёмки** | Ст. 720 ГК РФ, ст. 14 ФЗ № 422-ФЗ | Подтверждение объёма и качества, гарантия 12 месяцев, отметка о формировании чека («Мой налог») |
| **Смета работ** | Стандарт проектной документации | Таблицы работ и материалов, скидки, итоговая сумма к оплате, подписи сторон |
| **Excel (.csv)** | Формат CSV UTF-8 с BOM | Готовая таблица для открытия в Microsoft Excel / LibreOffice Calc |

## 🚀 Быстрый старт и запуск

### Настройка веб-сайта
1. Клонируйте репозиторий или скачайте файлы проекта:
   ```bash
   git clone https://github.com/mmmatveyz/voltgroup.git
   cd voltgroup
   ```
2. Откройте `index.html` или `estimate.html` в любом современном браузере.
3. Для публикации сайта подходит любой веб-хостинг (Beget, Timeweb, Netlify, Vercel, GitHub Pages).

### Настройка и запуск Telegram-бота
1. Установите зависимости:
   ```bash
   pip install pyTelegramBotAPI requests
   ```
2. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте токен.
3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).
4. Задайте переменные окружения или укажите их в `server.py`:
   ```bash
   # Windows PowerShell
   $env:BOT_TOKEN="ВАШ_ТЕЛЕГРАМ_ТОКЕН"
   $env:ADMIN_CHAT_ID="ВАШ_TELEGRAM_ID"

   # Linux / macOS
   export BOT_TOKEN="ВАШ_ТЕЛЕГРАМ_ТОКЕН"
   export ADMIN_CHAT_ID="ВАШ_TELEGRAM_ID"
   ```
5. Запустите бота:
   ```bash
   python server.py
   ```
6. Откройте чат с вашим ботом в Telegram и отправьте команду `/start`. На экране появится интерактивное меню с кнопками для управления объектами.

## 🏷 Обновление цен и галереи

### Как обновить цены на работы (`prices.json`)
Файл `prices.json` содержит категории и список работ:
```json
[
  {
    "category": "Штробление и кабель",
    "items": [
      {
        "id": "sh-1",
        "name": "Штробление газобетон / пеноблок",
        "unit": "м.п.",
        "price": 250
      },
      {
        "id": "sh-2",
        "name": "Штробление кирпич",
        "unit": "м.п.",
        "price": 350
      }
    ]
  }
]
```
Измените поле `price` у нужной услуги или добавьте новый пункт — калькулятор подтянет обновленные расценки автоматически.

### Как добавить фото в галерею (`gallery/gallery-config.json`)
1. Сохраните оптимизированное изображение в папку `gallery/` (рекомендуется формат `.webp`, например, `gallery/work-05.webp`).
2. Добавьте запись в `gallery/gallery-config.json`:
```json
{
  "image": "./gallery/work-05.webp",
  "title": "Монтаж щита в 3-комнатной квартире",
  "description": "Сборка распределительного щита Hager на 36 модулей с защитой от скачков напряжения (УЗМ) и УЗО на влажные зоны.",
  "badges": ["Щитовое оборудование", "Квартира", "ГОСТ"]
}
```
