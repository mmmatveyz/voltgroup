## 🛠 Архитектура и модули

### 1. Публичный сайт
* **Стек:** Vanilla HTML, CSS, JavaScript (без сборщиков и тяжёлых фреймворков).
* **Дизайн:** Dark Tech / Cyberpunk стиль с неоновыми акцентами Cyan (`#00E5FF`). Полная адаптивность (Mobile, Tablet, Desktop).
* **Разделы сайта:**
  * `index.html` — Главная страница: УТП, калькулятор, каталог цен, интерактивная фотогалерея, карта районов СПб/ЛО, отзывы, FAQ и форма заявки.
  * `install/index.html` — Раздел услуг «Электромонтажные работы в СПб».
  * `engineering/index.html` — Раздел «Промышленная автоматизация и сборка щитов».
  * `works.html` — Портфолио выполненных объектов.
  * `contacts/index.html` — Контакты мастера и зоны выезда.
  * `privacy.html`, `offer.html`, `cookies.html` — Юридические страницы (обработка ПДн, оферта, cookie).
  * `404.html` — Страница ошибки 404.

### 2. Интерактивная смета и документооборот (`estimate.html`)
Рабочее место мастера для составления расчётов прямо на объекте или удалённо:
* **Каталог позиций:** Более 100 наименований работ из `static/data/prices.json`.
* **Умный поиск и фильтрация:** Поиск по названию и фильтр «Только выбранные».
* **Коэффициент сложности:** Переключатель `+20%` (сложные условия / монолит / бетон) для каждой позиции отдельно.
* **Произвольные работы и материалы:** Добавление пользовательских строк с мгновенным пересчётом на лету.
* **Управление закупкой материалов:** Режимы «Мастер закупает материалы» / «Материалы предоставляет заказчик».
* **Гибкая скидка:** Слайдер скидки от 0% до 20% с автоматическим пересчётом итогов.
* **Сохранение черновиков:** Экспорт и импорт сметы в файл `.json`.
* **Формирование документов (печать / PDF):**
  * 📑 **Договор бытового подряда:** официальный договор по ГК РФ (§ 1, 2 гл. 37) и 422-ФЗ со спецификацией работ и материалов.
  * 📄 **Коммерческое предложение (КП):** фирменный документ VoltGroup с подробными условиями и этапами.
  * 📝 **Акт сдачи-приёмки работ:** официальный акт по ст. 720 ГК РФ с гарантией 12 месяцев.
  * 🖨 **Печатная смета (PDF):** структурированная смета формата А4.
  * 📊 **Экспорт в Excel (.csv):** выгрузка таблицы с кодировкой UTF-8 BOM.
  * 📋 **Копирование для мессенджеров:** текст с форматированием для отправки в Telegram или другой мессенджер в 1 клик.

### 3. Telegram-бот и бэкенд (`server.py`)
Flask-приложение, работающее на хостинге Render:
* **Хранилище данных:** Google Таблицы через официальный API `gspread`.
* **Архитектура запуска:** 1 воркер (`gunicorn -w 1 -k gthread --threads 8`), состояния диалогов живут в памяти процесса с TTL 15 минут (`USER_STATE_TTL_SECONDS = 900`).
* **Управление объектами через Telegram:**
  * Интерактивное меню с Inline-кнопками.
  * 📊 **Прогресс работ:** выбор прогресса (0–100%) с сохранением в таблицу.
  * 🏗 **Смена этапа:** перевод между этапами (*Завоз материалов*, *Штробление и кабель*, *Сборка электрощита*, *Чистовой монтаж*, *Сдача объекта*).
  * 💰 **Внесение оплаты:** прибавление суммы (`50000`) или установка точного значения (`=120000`).
  * 🔗 **Ссылка клиенту:** генерация персональной защищённой ссылки с токеном доступа.
  * ➕ **Создание объекта:** создание новой строки с автоматической генерацией токена доступа.

### 4. Личный кабинет клиента (`client/index.html`)
* Персональный кабинет заказчика по ссылке вида `https://voltgroup-spb.ru/client/index.html?id=145&t=<токен>`.
* Защита от перебора: эндпоинт `/get-status` строго проверяет криптографический токен через `secrets.compare_digest`.
* Наглядная шкала готовности объекта и текущий этап.

## 🚀 Быстрый старт и запуск

### Локальный запуск фронтенда
> ⚠️ **Важно:** Страницы `index.html` и `estimate.html` загружают цены из `static/data/prices.json`, а галерею из `gallery/gallery-config.json` через JavaScript `fetch()`. По протоколу `file://` браузер блокирует эти запросы. Для локального просмотра запускайте локальный HTTP-сервер:

```bash
# В корневой папке проекта:
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080` или `http://localhost:8080/estimate.html`.

### Настройка и запуск бэкенда
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Подготовьте переменные окружения:
   * `BOT_TOKEN` — токен Telegram-бота от [@BotFather](https://t.me/BotFather).
   * `CHAT_ID` — ваш числовой ID в Telegram для доступа к управлению.
   * `SHEET_URL` — ссылка на Google Таблицу объектов.
   * `GOOGLE_CREDENTIALS` — JSON сервисного аккаунта Google Cloud.
   * `TELEGRAM_SECRET_TOKEN` — секретный токен вебхука Telegram.
   * `PORT` — порт сервера (по умолчанию `8000`).

3. Запуск сервера:
   * **Для разработки:**
     ```bash
     python server.py
     ```
   * **Для продакшена (Gunicorn):**
     ```bash
     gunicorn -w 1 -k gthread --threads 8 --bind 0.0.0.0:8000 server:app
     ```

## 🏷 Обновление цен и галереи

### Как обновить цены на работы (`static/data/prices.json`)
Файл `static/data/prices.json` является **единственным источником истины** для цен на сайте и в смете:
```json
{
  "install": {
    "categories": [
      {
        "name": "Черновые работы и подготовка",
        "items": [
          {
            "service": "Штробление бетона / монолита (до 20х20 мм, без пыли)",
            "unit": "п.м.",
            "price": 700
          }
        ]
      }
    ]
  }
}
```
Измените значение поля `price` — калькулятор и таблицы на сайте обновят расценки автоматически при следующей загрузке.

### Как добавить фото в галерею (`gallery/gallery-config.json`)
1. Сохраните оптимизированное изображение в папку `gallery/` в формате `.webp`.
2. Добавьте запись в `gallery/gallery-config.json`:
```json
{
  "image": "./gallery/work-05.webp",
  "title": "Монтаж щита в 3-комнатной квартире",
  "description": "Сборка распределительного щита на 36 модулей с защитой от скачков напряжения и УЗО.",
  "badges": ["Щитовое оборудование", "Квартира", "ГОСТ"]
}
```
