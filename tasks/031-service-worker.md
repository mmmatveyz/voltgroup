# Задача 031 — Service Worker: офлайн-работа на объекте

**Пункт аудита:** № 17 · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏸ отложено (07.10.2026, по решению заказчика; условие возврата: после закрытия остальных задач этапа 4)
**Файлы:** `sw.js`, `index.html` и другие страницы (регистрация), `estimate.html`

## Проблема

[sw.js](../sw.js) полностью закомментирован, регистрации `navigator.serviceWorker.register` нет ни на одной странице. Манифест PWA подключён ([index.html:37](../index.html#L37)), приложение устанавливается на телефон, но кэша нет — офлайн не откроется ничего.

Это самый болезненный пропуск именно для этого проекта: калькулятор сметы предназначен для работы **на объекте**, где интернета может не быть. Сейчас при пропаже сети мастер теряет доступ к прайсу, а черновики живут только в `localStorage` одного браузера.

## Шаги

1. Написать рабочий `sw.js`:
   - precache при установке: оболочка (`index.html`, `estimate.html`), `static/css/style.css`, `static/js/*.js`, `static/data/prices.json`, `gallery/gallery-config.json`, шрифты при необходимости;
   - стратегия: оболочка и прайс — `stale-while-revalidate`, изображения — `cache-first` с ограничением размера кэша;
   - обработка `activate`: удаление старых версий кэша.
2. Зарегистрировать SW на страницах, где нужен офлайн (в первую очередь `estimate.html`), с проверкой поддержки и обработкой ошибок регистрации.
3. Поднять версию кэша (`CACHE_NAME`) при изменении прайса или оболочки; продумать, как это делать автоматически (например, версия из даты сборки или ручной бамп по чек-листу).
4. Проверить, что обновление контента не «залипает»: пользователь не должен видеть устаревший прайс после релиза.
5. Не кэшировать запросы к API бэкенда (`/get-status`, `/send-message`) — только статику.

## Критерий готовности

Калькулятор открывается и считает без интернета после первого посещения; прайс доступен офлайн; обновления подхватываются после перезагрузки.

## Проверка

- DevTools → Application → Service Workers: воркер зарегистрирован и активен.
- Application → Cache Storage: список закэшированных ресурсов на месте.
- Network → Offline → перезагрузить `estimate.html`: страница открылась, прайс загрузился, расчёт работает.
- Offline → сохранить черновик и перезагрузить: черновик на месте.
- Онлайн после правки прайса: после перезагрузки значения обновились.
