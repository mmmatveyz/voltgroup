# Задача 021 — Баннер согласия на cookies

**Пункт аудита:** № 12 · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏳ не начато
**Файлы:** все страницы (7 шаблонов), `static/css/style.css`, `static/js/cookies.js` (новый), `server.py` (убрать `X-XSS-Protection` — см. задачу 020)

## Проблема

Яндекс.Метрика инициализируется с `webvisor:true, clickmap:true` ([index.html:241-250](../index.html#L241-L250) и аналогично на `estimate`, `works`, `privacy`, `offer`, `cookies`, `404`) без какого-либо согласия. Страница политики есть ([cookies.html](../cookies.html)), механизма согласия нет ни на одном шаблоне. Вебвизор записывает действия пользователя, включая ввод в формы.

## Шаги

1. Создать `static/js/cookies.js`: баннер снизу экрана с текстом, кнопками «Принять» и «Только необходимые», ссылкой на `cookies.html`.
2. Хранить выбор в `localStorage` (`vg_consent` = `all` | `necessary`), не показывать баннер повторно.
3. **Инициализировать Метрику только при `vg_consent === 'all'`** — сейчас счётчик грузится безусловно в `<head>`; перенести инициализацию в JS после проверки согласия.
4. На странице `cookies.html` добавить кнопку «Изменить настройки» (сброс `vg_consent` и повторный показ баннера).
5. Стилизовать баннер в рамках существующего дизайна (тёмная тема, cyan-акцент), не перекрывать мобильное меню и кнопки связи.
6. Учесть доступность: баннер не должен ломать фокус, кнопки доступны с клавиатуры.

## Критерий готовности

До согласия Метрика не загружается; после «Принять» — загружается; выбор сохраняется между визитами.

## Проверка

- DevTools → Application → Local Storage: после клика появляется `vg_consent`.
- Network: до согласия нет запросов к `mc.yandex.ru`; после — есть.
- Перезагрузка страницы → баннер не показывается повторно.
- `cookies.html` → «Изменить настройки» → баннер вернулся.
- Метрика в реальном времени показывает визит после согласия.
