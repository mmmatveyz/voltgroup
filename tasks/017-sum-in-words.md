# Задача 017 — Сумма прописью в документах

**Пункт аудита:** № 10 · из [AUDIT.md](../AUDIT.md)
**Статус:** ✅ завершено (06.10.2026)
**Файлы:** `estimate.html` (или новый `static/js/money.js`)

## Проблема

В договоре сумма указана только цифрами: `составляет: <strong>${totals.worksFinal.toLocaleString('ru-RU')} (рублей)</strong>` ([estimate.html:2033](../estimate.html#L2033)). Функции преобразования числа в текст в проекте нет. Аналогично в акте ([estimate.html:1662](../estimate.html#L1662)) и спецификации ([estimate.html:2126](../estimate.html#L2126)).

## Шаги

1. Реализовать `numberToWords(sum)` с корректными склонениями: «одна тысяча», «две тысячи», «пять тысяч», «двадцать один рубль», «две копейки».
2. Поддержать разряды до миллионов включительно (суммы по объектам могут быть шестизначными, запас до 999 999 999).
3. Учесть женский род для тысяч («одна тысяча», «две тысячи»), мужской для рублей.
4. Подставлять результат: в договоре п. 2.1 — «(сумма прописью) рублей NN копеек»; в акте — в строке итога; в спецификации — в строке «ВСЕГО К ОПЛАТЕ».
5. Копейки выводить, даже если их нет: «00 копеек» — так требуют деловые документы.
6. Вынести функцию в отдельный файл, если задача 019 (разбиение `estimate.html`) выполняется параллельно.

## Критерий готовности

Во всех трёх местах сумма продублирована прописью и совпадает с цифрами.

## Проверка

Написать быстрый тест (Node или в консоли браузера) на набор значений:

| Вход | Ожидание |
|---|---|
| 1 | один рубль 00 копеек |
| 2 | два рубля 00 копеек |
| 5 | пять рублей 00 копеек |
| 11 | одиннадцать рублей 00 копеек |
| 21 | двадцать один рубль 00 копеек |
| 1000 | одна тысяча рублей 00 копеек |
| 2000 | две тысячи рублей 00 копеек |
| 11000 | одиннадцать тысяч рублей 00 копеек |
| 1000001 | один миллион один рубль 00 копеек |
| 123456.78 | сто двадцать три тысячи четыреста пятьдесят шесть рублей 78 копеек |

Дополнительно: собрать смету, сгенерировать договор и акт, глазами сверить пропись с цифрами.
