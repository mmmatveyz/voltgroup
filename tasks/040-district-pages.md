# Задача 040 — Страницы под районы СПб и ЛО

**Направление:** SEO · контент и семантика · из [AUDIT.md](../AUDIT.md) (SEO-раздел)
**Статус:** ⏳ не начато
**Файлы:** новые каталоги (например, `elektromontazh-primorsky/`, `elektromontazh-vsevolozhsk/`), `sitemap.xml`, внутренние ссылки

## Проблема

Сайт таргетирует «Санкт-Петербург и Ленинградская область» целиком. По запросам с указанием района или города конкуренция ниже, а релевантность выше — но посадочных страниц под них нет. Сейчас это одна страница `index.html`, которая не может быть релевантной одновременно для Приморского района, Всеволожска и Гатчины.

Это самый ёмкий источник роста по локальному SEO, и он же самый трудоёмкий: нужны отдельные страницы с уникальным текстом.

## Шаги

1. **Собрать семантику.** Выписать реальные запросы: «электромонтаж <район>», «электрик <город ЛО>», «сборка щита <район>». Источники: Вебмастер («Поисковые запросы»), Яндекс.Вордстат, подсказки поиска.
2. **Выбрать 5-8 приоритетных направлений** по двум критериям: есть спрос и есть уже выполненные объекты. Начинать с тех районов, где объекты есть — портфолио по району резко повышает доверие и уникальность.
3. **Создать страницы** `elektromontazh-<район>/index.html` по образцу `install/index.html` (единый стиль, тот же CSS, `?v=` синхронизирован — см. задачу 022).
4. **Текст на каждой странице должен быть уникальным:** район, ЖК и типы домов, особенности (монолит, панель, старый фонд — влияет на штробление и щиты), примеры выполненных объектов с фото, сроки выезда, цены. Копипаста с перестановкой названия района не работает и приводит к фильтру за малополезный контент.
5. **Микроразметка:** `Service` с `areaServed`, `BreadcrumbList`, при наличии объектов — `LocalBusiness`.
6. **Внутренние ссылки:** с главной и из разделов на районные страницы; между районными страницами — блок «соседние районы». Без ссылок страницы не обойдутся.
7. **Добавить в sitemap** с реальным `lastmod` (задача 036), отправить на переобход (задача 035).
8. Следить, чтобы не появилось дублей: canonical на каждой странице — свой.

## Критерий готовности

5+ районных страниц с уникальным текстом и портфолио по району; они в sitemap, связаны внутренними ссылками, открываются с кодом 200.

## Проверка

- Через 3-4 недели после публикации: Вебмастер → «Поисковые запросы» → появились показы по запросам с названием района.
- Проверить уникальность текстов: сравнение страниц между собой (любой антиплагиат или ручное сравнение абзацев).
- Отключить JS → текст и контакты видны (задача 037).
- `site:voltgroup-spb.ru` → новые страницы появились в индексе.

## Примечание

Это самая долгая задача из SEO-блока: 5 страниц по 3000-5000 знаков уникального текста каждая. Разумно делать по одной странице в неделю, а не всё сразу — заодно поисковики увидят регулярные обновления.
