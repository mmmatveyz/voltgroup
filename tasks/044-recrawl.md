# Задача 044 — Переобход страниц в Яндекс.Вебмастере

**Направление:** SEO · внешний контур · приоритет №1 после замеров 06.10.2026
**Статус:** ⏳ не начато — **действие человека, срочное**
**Где:** Яндекс.Вебмастер → Индексирование → Переобход страниц

## Действие

Отправить на переобход 9 URL из sitemap и проверить статус файла sitemap. **Агент это выполнить не может** — нужен доступ в панель Яндекс.Вебмастера.

## Почему это срочно

По данным замеров от 06.10.2026:

- **Последнее посещение роботом Яндекса — 19.07.2026.** Данные Вебмастера покрывают период с 4 августа по 3 октября 2026 — то есть **за 2,5 месяца робот не переобходил страницы**.
- При этом SEO-правки (canonical, микроразметка, sitemap, метатеги) выложены **29.09.2026** (коммиты `67221fe`, `4884302`), а security-правки по кабинету — 06.10.2026.
- В Вебмастере `/install/`, `/engineering/`, `/contacts/` до сих пор помечены **«Канонический адрес не указан»**, хотя в коде у всех трёх прописан правильный `canonical`:

```
install/index.html      → https://voltgroup-spb.ru/install/
engineering/index.html  → https://voltgroup-spb.ru/engineering/
contacts/index.html     → https://voltgroup-spb.ru/contacts/
```

Вывод: **Яндекс просто не видел текущую версию сайта.** Он держит устаревшие данные июльского обхода. Никакой поломки в коде нет — есть задержка обхода, которую нужно снять вручную.

## Шаги

1. Открыть **Индексирование → Переобход страниц**.
2. Отправить на переобход **все 9 URL из sitemap**:
   - `https://voltgroup-spb.ru/`
   - `https://voltgroup-spb.ru/install/`
   - `https://voltgroup-spb.ru/engineering/`
   - `https://voltgroup-spb.ru/contacts/`
   - `https://voltgroup-spb.ru/estimate.html`
   - `https://voltgroup-spb.ru/works.html`
   - `https://voltgroup-spb.ru/privacy.html`
   - `https://voltgroup-spb.ru/offer.html`
   - `https://voltgroup-spb.ru/cookies.html`
3. Дополнительно отправить варианты, которые Яндекс пометил как исключённые:
   - `https://voltgroup-spb.ru/index.html`
   - `https://voltgroup-spb.ru/index`
4. В **Индексирование → Файлы Sitemap** убедиться, что `https://voltgroup-spb.ru/sitemap.xml` загружен и обработан (отдельно от переобхода URL).
5. Проверить вкладку **«Все страницы»** в разделе «Страницы в поиске»: сколько страниц реально участвует в поиске. Именно эта выгрузка (а не «Последние изменения») пришла пустой — 0 строк.
6. Записать в журнал [AGENT_STATE.md](../AGENT_STATE.md): дату отправки, список URL, ответ Вебмастера (лимит на количество URL в сутки).
7. **Через 3-7 дней перепроверить:** исчез ли статус «Канонический адрес не указан» у `/install/`, `/engineering/`, `/contacts/`; появились ли страницы в «Все страницы».

## Критерий готовности

9 URL отправлены на переобход и обработаны; через неделю в «Страницах в поиске» → «Все страницы» есть хотя бы часть сайта, а у разделов пропал статус про неуказанный canonical.

## Проверка

- Индексирование → Переобход страниц → в очереди видны отправленные URL, статус «Добавлено в очередь» / «Обойдено».
- Индексирование → Статистика обхода → появилась дата посещения свежее 19.07.2026.
- Через 3-7 дней: у `/install/`, `/engineering/`, `/contacts/` в списке изменений статус сменился с «Канонический адрес не указан» на «В поиске».
- Загрузка архива «Все страницы» → файл содержит строки данных.

## Что НЕ нужно делать

- **Не менять `canonical` в коде** — он уже правильный и совпадает с sitemap посимвольно (проверено 06.10.2026).
- Не переписывать sitemap ради «свежести» до отправки на переобход: сначала снять задержку обхода, иначе правки уйдут в тот же устаревший снимок.
