# Задачи проекта VoltGroup

**Что это.** Одна карточка = одна задача. Карточка самодостаточна: проблема, файлы, конкретные шаги, критерий готовности и способ проверки. Сессия агента = одна карточка, чтобы контекст не забивался смежными темами.

**Откуда взялось.** Карточки разбиты из [AUDIT.md](../AUDIT.md) — там исходный разбор и обоснование приоритетов.

**Как работать:**
1. Прочитать [AGENTS.md](../AGENTS.md) (правила) и [AGENT_STATE.md](../AGENT_STATE.md) (журнал и текущий фокус).
2. Взять **одну** карточку со статусом ⏳.
3. После завершения — отметить статус в карточке **и** записать результат в [AGENT_STATE.md](../AGENT_STATE.md) по шаблону из `AGENTS.md` §7.
4. Не считать задачу выполненной без вывода команды проверки из карточки.

> ⚠️ Номера строк в карточках — подсказка на момент аудита (ревизия `4884302`). После правок они сдвигаются: искать по названию функции, а не по номеру.

**Легенда:** ✅ выполнено · 🔄 в работе · ⏳ не начато · ⏸ приостановлено · 💬 требует решения человека
