# Задача 019 — Тесты расчёта и генерации документов

**Пункт аудита:** № 22 · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏳ не начато
**Файлы:** новый `tests/`, `requirements-dev.txt` (при необходимости)

## Проблема

В проекте есть расчётная логика (скидка, коэффициент сложности +20%, материалы, итоги) и генерация четырёх юридических документов, но нет ни одного теста. Изменение цены в JSON или правка вёрстки ломают формулу молча — так и появилось расхождение баз расчёта (задача 016). Для агентной разработки это критично: агент не может «почувствовать» регрессию, ему нужна команда, которая скажет «сломано».

## Шаги

1. Ввести `tools/check.py` — единая команда проверки:
   - синтаксис Python (`ast.parse` для `server.py`);
   - валидность JSON: `static/data/prices.json`, `gallery/gallery-config.json`, `manifest.json`, `yandex-manifest.json`;
   - существование всех файлов галереи, упомянутых в конфиге;
   - отсутствие `.jpg`-ссылок в конфиге галереи;
   - рассинхрон `?v=` между страницами (задача 022);
   - отсутствие неэкранированных подстановок `${...}` в местах генерации HTML (эвристика по шаблонам рядом с `innerHTML`/`document.write`).
2. Добавить тесты расчёта (pytest для Python-части и/или Node-скрипт для JS-функций):
   - `calculateTotals` при скидке 0/10/20%;
   - коэффициент сложности +20% на отдельной позиции;
   - включённые и выключенные материалы;
   - округление до целых рублей.
3. Добавить тест суммы прописью (таблица значений из задачи 017).
4. Добавить смоук-тест документов: генерация четырёх документов не падает и содержит одну и ту же итоговую сумму (проверка задачи 016).
5. Зафиксировать в [AGENTS.md](../AGENTS.md) §3 требование: перед завершением задачи запускать `python tools/check.py` и приводить вывод.

## Критерий готовности

Одна команда проверяет расчёты, документы, конфиги и целостность ссылок; её можно запускать после любой правки.

## Проверка

- `python tools/check.py` на текущем состоянии → проходит.
- Намеренно испортить данные (например, убрать `.webp`-файл или сломать JSON) → скрипт сообщает об ошибке с указанием файла.
- Намеренно поменять сумму только в акте → тест расхождения баз падает.
