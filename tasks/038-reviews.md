# Задача 038 — Отзывы: вывод на сайт и разметка

**Направление:** SEO · доверие и конверсия · из [AUDIT.md](../AUDIT.md) (SEO-раздел)
**Статус:** ⏳ не начато
**Файлы:** `index.html`, возможно `works.html`

## Проблема

На сайте есть блок отзывов, но нет их структурированного источника и разметки. При этом отзывы — один из немногих факторов, который одновременно двигает и позиции (свежий пользовательский контент, поведенческие), и конверсию. Для локальных услуг отзывы в Яндекс.Картах весят больше, чем весь on-page SEO.

Дополнительно: без разметки отзывы не дают расширенного сниппета со звёздами в выдаче, хотя микроразметка `LocalBusiness` на главной уже есть и готова к этому.

## Шаги

1. Собрать реальные отзывы: из Яндекс.Карт, 2ГИС, Telegram, переписок — **с согласия клиентов** (учитывать 152-ФЗ: имя и адрес объекта без разрешения публиковать нельзя; лучше «Мария, ЖК …» или инициалы).
2. Разместить на сайте блок отзывов с указанием источника и даты, со ссылкой на карточку в Картах («смотреть все отзывы»).
3. Добавить микроразметку `Review` / `AggregateRating` внутрь существующего `LocalBusiness` ([index.html](../index.html) — блок JSON-LD с `LocalBusiness`).
4. **Важно:** разметку ставить только на реальные отзывы с реальными оценками. Нарисованные рейтинги — риск санкций со стороны поисковиков.
5. Настроить сбор новых отзывов: просить клиента оставить отзыв в Картах после сдачи объекта. Логичный момент — тот же, когда бот отправляет ссылку на кабинет ([server.py:500-505](../server.py#L500)).
6. Проверить, что блок отзывов виден без JS (совпадает с задачей 037).

## Критерий готовности

На сайте не менее 5 реальных отзывов с датами и источниками; разметка `Review`/`AggregateRating` валидна; есть механизм запроса новых отзывов.

## Проверка

- Валидатор структурированных данных Яндекса и Google Rich Results Test → разметка отзывов распознана без ошибок.
- Отключить JS → отзывы видны.
- Через 2 недели после внедрения: в Вебмастере появились показы по запросам с названием компании.
- Проверить, что в разметке нет отзывов, которых нет в тексте страницы (обязательное требование поисковиков).
