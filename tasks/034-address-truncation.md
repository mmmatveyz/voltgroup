# Задача 034 — Обрезка адреса и текст для клиента

**Пункт аудита:** № 23 · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏳ не начато
**Файлы:** `server.py`

## Проблема

В списке объектов адрес обрезается до 20 символов ([server.py:196](../server.py#L196)): при совпадении начала адреса у нескольких объектов кнопки становятся неразличимыми. В тексте для клиента ([server.py:500-504](../server.py#L500)) адрес подставляется из ячейки без проверки на пустоту в части сценариев, а сам текст фиксирован.

## Шаги

1. В кнопках списка использовать ID + короткий различимый фрагмент адреса (10-12 символов): `№145 · ул. Ленина…`.
2. При совпадении коротких адресов добавлять различающий суффикс (например, номер дома или порядковый индекс).
3. В тексте для клиента всегда указывать полный адрес; при пустой ячейке — нейтральная формулировка без «по объекту №X» в скобках.
4. Проверить, что текст для пересылки не содержит технических деталей (id во фразе уже есть, это нормально) и корректно переживает HTML-экранирование.
5. Учесть лимит длины текста Telegram — при большом адресе сообщение не должно обрезаться.

## Критерий готовности

Даже при похожих адресах мастер выбирает нужный объект без ошибки; клиент получает понятное сообщение с полным адресом.

## Проверка

- Создать три объекта с адресами, начинающимися одинаково (`ул. Ленина, 24`, `ул. Ленина, 24 к2`, `ул. Ленина, 240`) → открыть список объектов → кнопки различимы.
- Нажать «🔗 Ссылка клиенту» для каждого → текст содержит полный адрес нужного объекта.
- Объект с пустым адресом → сообщение не содержит пустых скобок и битой разметки.
