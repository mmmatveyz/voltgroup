# Задача 022 — Синхронизировать `?v=` во всех страницах

**Пункт аудита:** № 20 · из [AUDIT.md](../AUDIT.md)
**Статус:** ✅ завершено (07.10.2026)
**Файлы:** `404.html`, `cookies.html`, `offer.html`, `privacy.html`, `install/index.html`, `engineering/index.html`, `contacts/index.html`

## Проблема

Версии кэш-бэстинга разошлись: `?v=2.1` в `404.html`, `cookies.html`, `offer.html`, `privacy.html`; `?v=2.3` в `index.html`, `estimate.html`, `works.html`; во вложенных папках (`install/`, `engineering/`, `contacts/`) параметра нет вовсе. После правки CSS часть страниц отдаёт старую версию из кэша — расхождения в вёрстке между разделами.

## Шаги

1. Зафиксировать единый актуальный номер версии стилей (например, `v=2.4`, раз CSS с тех пор менялся).
2. Проставить его во всех 10 HTML-файлах, включая вложенные папки.
3. Заодно проверить корректность относительных путей к CSS во вложенных папках (`../static/css/style.css`).
4. Добавить проверку рассинхрона в `tools/check.py` (задача 019): собрать все значения `?v=` из HTML и убедиться, что они одинаковые.
5. Зафиксировать в [AGENTS.md](../AGENTS.md) §2.4 правило: при правке CSS обновлять версию на всех страницах.

## Критерий готовности

Один номер версии во всех страницах; после правки CSS обновление видно везде.

## Проверка

- Поиск по репозиторию `style.css?v=` → все значения идентичны.
- Открыть каждую из 10 страниц → стили применены (проверить, например, цвет акцента `#00E5FF`).
- В DevTools → Network: `style.css?v=<версия>` загружается на каждой странице.
