# Задача 014 — Убрать дубли и мёртвые файлы

**Пункт аудита:** № 28 (🟠 важно) · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏳ не начато
**Файлы:** `yandex-tableau-logo.png`, `assets/`, `site.webmanifest`, `manifest.json`, пустая `static/js/`

## Проблема

- `yandex-tableau-logo.png` лежит в трёх местах с идентичным содержимым (5937 байт): корень, `assets/`, `assets/images/`.
- `manifest.json` и `site.webmanifest` содержат одинаковый текст, подключён только `manifest.json`.
- Папка `static/js/` пуста.
- 14 неиспользуемых `.jpg` в `gallery/` (отдельная задача 010).

## Шаги

1. Определить, на какую копию логотипа реально ссылаются `yandex-manifest.json` и страницы: поиск по `yandex-tableau-logo`.
2. Оставить один файл в каноничном месте (`assets/images/`), остальные удалить, ссылки поправить.
3. Удалить `site.webmanifest`, если на него нет ссылок (проверить тегами `rel="manifest"` на всех страницах).
4. Оставить `static/js/` — она понадобится для задач 011, 018, 022; при желании добавить `.gitkeep`.
5. Убедиться, что после удалений нет битых ссылок в HTML.

## Критерий готовности

Один логотип, один манифест, ни одной ссылки в никуда.

## Проверка

- Поиск по репозиторию имён удалённых файлов → пусто.
- `python -m http.server` → открыть каждую страницу и проверить вкладку Network на 404.
- Отдельно открыть `yandex-manifest.json` — ссылка на логотип резолвится.
