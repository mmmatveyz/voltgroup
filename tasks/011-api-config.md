# Задача 011 — Единая константа адреса API

**Пункт аудита:** № 8 (🟠 важно) · из [AUDIT.md](../AUDIT.md)
**Статус:** ⏳ не начато
**Файлы:** новый `static/js/config.js`, `index.html`, `client/index.html`, CSP на всех страницах

## Проблема

`https://voltgroup-bot.onrender.com` захардкожен более чем в 10 местах: в `connect-src` CSP каждой страницы и в вызовах `fetch` ([index.html:1148](../index.html#L1148), [1191](../index.html#L1191) и дубли; [client/index.html:320](../client/index.html#L320)). Смена адреса бэкенда требует ручной правки всех файлов, причём правка CSP забывается первой — сайт молча теряет формы.

## Шаги

1. Создать `static/js/config.js` с одной константой: `window.VG_API = 'https://voltgroup-bot.onrender.com';`
2. Подключить его **первым** скриптом на страницах, где есть запросы к API (`index.html`, `client/index.html`).
3. Заменить литералы в `fetch` на `${window.VG_API}/...` либо на уже собранную переменную.
4. В CSP оставить домен как есть (CSP всё равно правится руками), но добавить комментарий рядом: «при смене домена API обновить здесь и в `static/js/config.js`».
5. Зафиксировать в [AGENTS.md](../AGENTS.md) §2.4 требование: новые запросы к API — только через `window.VG_API`.

## Критерий готовности

Адрес API встречается как значение ровно в одном месте кода; CSP упоминает его отдельно и помечен комментарием.

## Проверка

- Поиск по репозиторию `onrender.com` → только `static/js/config.js` и строки CSP.
- Открыть `index.html` локально → отправить заявку → уведомление приходит.
- Открыть `client/index.html?id=…&t=…` → данные загружаются.
- Console: `window.VG_API` возвращает адрес.
