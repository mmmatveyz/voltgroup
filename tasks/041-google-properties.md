# Задача 041 — Google Search Console и Google Business Profile

**Направление:** SEO · внешний контур · из [AUDIT.md](../AUDIT.md) (SEO-раздел)
**Статус:** ⏳ не начато
**Где:** Google Search Console, Google Business Profile, `index.html`

## Проблема

Сайт ориентирован на Яндекс (Метрика, Вебмастер, Бизнес — всё заведено). Google — отдельная поисковая система со своей индексацией и своими панелями. Если аккаунтов нет, сайт может вообще не индексироваться в Google, а вы этого не увидите.

Для услуг в Санкт-Петербурге Google даёт меньший, но реальный поток, плюс часть клиентов ищет через него.

## Шаги

1. **Google Search Console**: добавить ресурс `https://voltgroup-spb.ru`, подтвердить владение через DNS TXT-запись (предпочтительно) или HTML-файл.
2. Отправить `sitemap.xml`, дождаться обработки, посмотреть «Покрытие» / «Индексирование страниц»: сколько страниц в индексе, что исключено и почему.
3. **Google Business Profile**: создать карточку организации. Категории — по аналогии с Яндекс.Бизнесом (задача 039): «Electrician», «Electrical installation service».
4. **NAP-консистентность:** название, телефон, регион — **посимвольно те же**, что в Яндекс.Бизнесе и на сайте. Это обязательное условие, расхождение ослабляет обе карточки.
5. Разместить `google-site-verification` (если подтверждение через meta-тег) в `<head>` главной — тег должен попасть на все варианты домена (с `www` и без).
6. Проверить, что сайт не закрыт от Google: `robots.txt` разрешает обход (для Google нужен отдельный `User-agent: Googlebot`, текущий `User-agent: *` его покрывает — верно, но проверить, что нет конфликтов).
7. Проверить скорость через PageSpeed Insights — Google использует Core Web Vitals, а вес галереи (задачи 010, 037) влияет напрямую.

## Критерий готовности

Оба аккаунта активны, sitemap обработан, карточка организации опубликована, данные совпадают с Яндексом и сайтом.

## Проверка

- Search Console: «Покрытие» → число проиндексированных страниц (сравнить с 9+sitemap).
- Google: `site:voltgroup-spb.ru` → страницы в индексе.
- Google Maps: поиск `VoltGroup Санкт-Петербург` → карточка находится.
- PageSpeed Insights → Core Web Vitals (LCP, CLS, INP) в «зелёной» зоне на мобильных.
