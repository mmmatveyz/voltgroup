# Задача 010 — Галерея: убрать мёртвые JPEG и облегчить изображения

**Пункт аудита:** № 7 (🟠 важно) · из [AUDIT.md](../AUDIT.md)
**Статус:** ✅ завершено (06.10.2026)
**Файлы:** `gallery/*.jpg` (удаление), `gallery/*.webp` (пережатие), `works.html`, `index.html`

## Проблема

14 JPEG общим весом **25,2 MB** не упоминаются нигде: в [gallery/gallery-config.json](../gallery/gallery-config.json) только расширение `.webp` (14 совпадений). Сами WebP (13,5 MB) пережаты слабо — `floor-boxes-08.webp` весит 1,64 MB. Плюс `works.html` ставит изображения фоном через `backgroundImage` ([works.html:482](../works.html#L482)), что исключает `loading="lazy"` и `srcset`: качается всё сразу.

## Шаги

1. Убедиться, что на `.jpg` нет ссылок (поиск по всем `.html`, `.json`, `.css`, `.js`), после чего удалить все `gallery/*.jpg`. Исходники при необходимости хранить вне репозитория.
2. Пережать `.webp` до ≤300 KB: качество 75-80, ширина 1600 px (`cwebp -q 78 -resize 1600 0`). Проверить визуально, что артефактов нет.
3. В `works.html` заменить `background-image` на `<img loading="lazy" decoding="async">` с `object-fit: cover`, добавить `srcset` (например, 800/1200/1600) и `sizes`.
4. Поправить CSS `.gallery-img` так, чтобы `<img>` занял место фона (сохранить пропорции и обрезку).
5. Проверить, что лайтбокс ([works.html:513](../works.html#L513)) продолжает работать с новым тегом.
6. Сделать то же для галереи на главной ([index.html:917](../index.html#L917) — загрузка конфига).

## Критерий готовности

Общий вес изображений галереи ≤ 4-5 MB; на медленном соединении карточки догружаются по мере прокрутки.

## Проверка

- `git status` → удалённые `.jpg` видны как deleted.
- Суммарный размер: `Get-ChildItem gallery -File | Measure-Object Length -Sum`.
- DevTools → Network с throttling «Slow 3G» → открыть `works.html`, убедиться, что загружаются не все изображения сразу.
- Визуально сверить 3-4 карточки и лайтбокс.
