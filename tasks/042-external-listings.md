# Задача 042 — Внешние каталоги и упоминания

**Направление:** SEO · внешний контур · из [AUDIT.md](../AUDIT.md) (SEO-раздел)
**Статус:** ⏳ не начато
**Где:** 2ГИС, Авито Услуги, Профи.ру, Яндекс.Услуги, локальные каталоги

## Проблема

Локальная выдача ранжирует в том числе по упоминаниям и ссылкам с внешних ресурсов. Сейчас у проекта, судя по репозиторию, таких упоминаний нет — кроме Яндекс.Бизнеса. Это главный дефицит: техническое SEO сделано, а «массы» для ранжирования нет.

## Шаги

1. **Составить список площадок** в порядке ценности для электромонтажа в СПб:
   - 2ГИС — обязательна карточка, сильный локальный сигнал;
   - Авито Услуги — высокий трафик по коммерческим запросам;
   - Профи.ру, Юла Услуги — трафик и упоминания;
   - Яндекс.Услуги — связана с карточкой в Бизнесе;
   - локальные каталоги и городские порталы;
   - профильные: строительные форумы, ЖК-сообщества, группы ВК районов.
2. **Везде использовать одинаковый NAP** (название, телефон, регион, ссылка) — то же правило, что в задачах 039 и 041. Расхождения ослабляют сигналы.
3. **На каждой площадке указать полный набор услуг** и ссылку на профильную страницу сайта, а не всегда на главную: для электромонтажа квартир — на `/install/`, для станков — на `/engineering/`.
4. **Заполнить профили полностью** (фото объектов, описание, цены «от»). Площадки ранжируют заполненные профили выше.
5. **Не закупать ссылки** и не размещаться на «ссылочных фермах»: для локального бизнеса риск санкций выше выгоды.
6. **Вести учёт:** таблица «площадка — дата регистрации — логин — ссылка на профиль — статус модерации». Хранить в проекте (`docs/seo-mentions.md`), чтобы не потерять.

## Критерий готовности

Профили созданы минимум на 5 площадках, данные везде совпадают, ссылки ведут на релевантные страницы. Есть учётная таблица.

## Проверка

- Поиск в Яндексе по названию компании и телефону (`+7 905 208-42-84`) → находятся внешние профили.
- Проверить каждую ссылку из таблицы: открывается, ведёт на нужную страницу сайта, не битая.
- Через 1-2 месяца: Вебмастер → «Ссылки» → видны внешние ссылки на домен.
- Вебмастер → «Поисковые запросы» → рост показов по коммерческим запросам.

## Примечание

Это ручная работа, которую агент не выполнит за вас: нужны регистрации с подтверждением телефона и модерация. Задача агента — подготовить тексты описаний, следить за консистентностью NAP и вести таблицу.
