# Задача 026 — Убрать `document.write` при печати документов

**Пункт аудита:** № 26 · из [AUDIT.md](../AUDIT.md)
**Статус:** ✅ завершено (07.10.2026)
**Файлы:** `static/js/documents.js`, `tools/test_doc_smoke.js`, `tools/check.py`

## Проблема

Генераторы документов пишут HTML через `document.write` в новое окно: [estimate.html:1290](../estimate.html#L1290), [1514](../estimate.html#L1514), [1700](../estimate.html#L1700), [2141](../estimate.html#L2141). Приём устаревший, при неполной загрузке окна возможны гонки. При этом для CSV уже используется надёжный подход через `Blob` + `URL.createObjectURL` ([estimate.html:1912](../estimate.html#L1912)).

## Шаги

1. Заменить `document.write` на единый хелпер: собрать HTML в `Blob` с типом `text/html;charset=utf-8`, создать `URL.createObjectURL`, открыть в новом окне/вкладке, после `load` вызвать печать, затем `URL.revokeObjectURL`.
2. Сохранить текущее поведение: пользователь видит документ и кнопки «Печать / Сохранить в PDF» и «Закрыть».
3. Убедиться, что кириллица не ломается: `<meta charset="UTF-8">` уже есть в шаблонах ([estimate.html:1156](../estimate.html#L1156) и др.), проверить также BOM не нужен.
4. Проверить все четыре документа: смету, КП, акт, договор.
5. Если задача 018 уже выполнена — править в `static/js/documents.js`, а не в HTML.

## Критерий готовности

Все четыре документа открываются и печатаются одинаково, без `document.write`; текст и суммы не повреждены.

## Проверка

- Сгенерировать каждый из четырёх документов → окно открылось, содержимое на месте.
- Нажать «Печать» → диалог печати, предпросмотр корректный.
- Проверить кириллицу и символ `₽`, длинные наименования работ.
- В консоли нет предупреждений, связанных с `document.write`.
