**Почему это важно.** `lastmod` — подсказка роботу, что страницу стоит переобойти. Сейчас карта сайта сообщает Яндексу, что шесть ключевых страниц не менялись с 29 сентября, а три юридические — с 12 сентября, хотя с тех пор на них появились блок отзывов, скелетоны загрузки, приём телефона в калькуляторе и баннер cookies. Робот, который и так не заходил с 19.07.2026, получает подтверждение «ничего нового».

## Шаги

1. Зафиксировать **правило** в [tasks/036](036-sitemap-fix.md) и в журнале: `lastmod` = дата последнего содержательного изменения страницы; изменение только версии `?v=` в ссылке на CSS последней датой **не считается**; массовые правки общего CSS не отражаются в `lastmod` каждой страницы (иначе подсказка обесценивается).
2. Обновить 11 значений `lastmod` по таблице выше.
3. Проверить, что ничего другого в sitemap не сломалось: состав URL (11), `changefreq`, `priority`, `Clean-param` в `robots.txt`.
4. Не ставить всем страницам «сегодня»: постоянно свежий `lastmod` поисковики учатся игнорировать.

## Критерий готовности

- У каждого из 11 URL `lastmod` совпадает с датой последнего содержательного изменения файла.
- Правило расчёта записано в `tasks/036` и в журнале.
- Состав URL не изменился: 11 записей, `client/index.html` в sitemap отсутствует (`noindex`).

## Проверка

1. Команда расчёта фактической даты по каждому файлу:
   ```powershell
   foreach ($f in 'index.html','install/index.html','engineering/index.html','estimate.html','works.html','contacts/index.html','privacy.html','offer.html','cookies.html','elektromontazh-murino/index.html','elektromontazh-bugry/index.html') {
     foreach ($line in (git log --format='%h %cs %s' -- $f)) {
       $h = ($line -split ' ')[0]
       $d = git show $h -- $f | Where-Object { $_ -match '^[+-]' -and $_ -notmatch '^(\+\+\+|---)' -and $_ -notmatch 'style\.css\?v=' }
       if ($d) { "{0,-34} {1}" -f $f, $line; break }
     }
   }
   ```
2. `python tools/check.py` → без новых ошибок (проверка `?v=` и отзывов не должна пострадать).
3. Валидность XML: открыть `sitemap.xml` в браузере или `python -c "import xml.dom.minidom,sys; xml.dom.minidom.parse('sitemap.xml'); print('XML OK')"`.
4. Сверить `loc` с фактическими адресами: 11 страниц из 13 HTML-файлов (`404.html` и `client/index.html` не индексируются).

## Что НЕ делать

- Не добавлять `noindex`/`Disallow` ни одной индексируемой странице.
- Не менять `robots.txt` и `canonical`.
- Не добавлять в sitemap `client/index.html`, `404.html` и страницу подтверждения Яндекса.
- Не подменять `lastmod` датой текущего дня «для свежести».
